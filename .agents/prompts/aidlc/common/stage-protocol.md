# Universal AIDLC stage protocol

Read the active stage packet before work. Read every listed role card, sensor,
the resolved KB snapshot, and the current intent. Do not infer absent context.

For an applicable stage: perform only the stated work, write factual evidence
to the matching intent section, run the listed sensors, then record completion.
For an inapplicable stage: record the fixed-condition reason and skip it. A
skip never fabricates an artifact. `approval-handoff` always stops for explicit
Approve, Re-plan, or Decline. No other command may bypass a stage.

# Universal AIDLC Delivery

Turn approved scope and architecture into one controlled implementation order.

## Own

- Approval handoff and delivery planning; support scope definition and units
  generation.
- Dependency order, decision points, risks, and evidence needed to move from
  design to construction.

## Required output

- Present one approval-ready handoff: outcome, scope/exclusions, acceptance,
  evidence, assumptions, risks, UI applicability, and resolved final gate.
- Sequence units by an explicit rationale such as dependency, risk reduction,
  or thin end-to-end feedback. Each increment has a completion proof.
- Keep the plan proportionate to the task and trace every unit to an acceptance
  item. Report a material scope change through the runtime re-plan path.

## Boundaries

The runtime returns the only legal next lifecycle action. Batch already-known
consecutive evidence once; never probe commands, retry altered arguments, or
invent team, worktree, Bolt, or parallel-agent state. Approval is the sole plan
approval boundary.

# AIDX package map

AIDX is a small, LLM-led goal-to-code lane with deterministic state checks.
Load the smallest package branch needed for the current goal.

- [SKILL.md](SKILL.md) — trigger, state contract, delegated skills, and safety
  rules.
- [references/index.md](references/index.md) — reference selector.
- [sessions/index.md](sessions/index.md) — runtime record layout.

The session files are resumable evidence for individual goals; they are not a
second source of reusable engineering guidance.

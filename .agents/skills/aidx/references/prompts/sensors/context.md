# Context evidence check

Governing protocol: [runtime protocol](../../protocols/runtime.md).

Pass when the goal record names the selected repository, applicable
instructions, relevant code evidence, material durable-context sources, and
remaining unknowns. A no-result discovery is evidence of no result, not
permission to invent a fact.

Use the owning discovery and knowledge skills for those boundaries. Do not
copy private knowledge into a reusable reference or grant the agent a broader
filesystem scope than the approved source permits.

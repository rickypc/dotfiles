# AIDX prompt map

These are focused prompt contracts for one state or decision. They are
selectively loaded guidance, not hidden states and not separate agents.

Prompt contracts consume the [role perspectives](../roles/index.md), selected
[engineering knowledge](../knowledge/index.md), and [protocols](../protocols/index.md).
The [evidence checks](sensors/index.md) below verify the resulting record;
they are not a second prompt router.

- [capture-goal.md](capture-goal.md) — turn a short request into one bounded
  goal record.
- [context-and-questions.md](context-and-questions.md) — inspect evidence and
  ask material questions.
- [plan-generation.md](plan-generation.md) — produce an implementation-ready
  plan with acceptance-to-proof mapping.
- [approval.md](approval.md) — present the sole approval decision.
- [implementation.md](implementation.md) — execute approved units and record
  deviations.
- [validation.md](validation.md) — test, repair, review, and close out.
- [sensors/index.md](sensors/index.md) — evidence, approval, context, and
  validation checks.
- [templates/index.md](templates/index.md) — lesson and implementation-record
  templates.

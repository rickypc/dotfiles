# Capture-goal prompt

Capture the user’s high-level outcome, concerns, constraints, repository, and
requested completion signal without turning the request into an epic or a
pre-written specification.

Create one goal record with the user’s words preserved, a short normalized
outcome, known exclusions, and the initial context. If the repository is not
clear, record it as an unknown to resolve during inspection. Move to context
inspection after the record exists.

Do not invent requirements, personas, architecture, a backlog, or acceptance
criteria that the user did not imply. Normalize wording only to improve
retrieval and traceability.

# Approval protocol

Approval is the single human authorization boundary for source changes.
Present one decision-ready plan containing outcome, scope, exclusions,
acceptance, evidence, assumptions, risks, ordered steps, focused proof, final
validation, and re-plan triggers.

Offer exactly these decisions: approve, re-plan, or decline. Do not infer
approval from an implementation request, silence, a summary, or an earlier
answer. A revision increments the plan version and requires approval again.

After approval, execute only the approved scope. If evidence changes behavior,
ownership, architecture, safety, or proof, stop editing and return to planning.

Operational check: [approval check](../prompts/sensors/approval.md).

# Reusable-reference index template

Use an `index.md` in every reference folder containing Markdown. The map is a
navigation aid, not a hidden process step or a second command owner.

Each focused guide should state the decision it supports, evidence it expects,
alternatives or risks it helps evaluate, and when it does not apply. Keep
examples pattern-based and free of machine-specific paths, private facts, and
secrets. Load a guide only when its concern is relevant; adding a file does not
make it mandatory for every goal.

For a folder map, list each child file with a relative link and one-line
purpose. Keep the map concise enough to select a small set of references from
the initial goal context.

# Skill Manager reference map

Load only the branch needed for the selected skill request. The map lists 5 entries, in order:

1. [skill-lifecycle.md](skill-lifecycle.md) - create, update, rename, and closeout method.
2. [agent-skills-guidance.md](agent-skills-guidance.md) - Agent Skills specification, description
   optimization, eval design, and script interfaces.
3. [train-protocol.md](train-protocol.md) - in-session training loop, metric definitions, blind
   measurement, never-worse gate, saturation, and suite runs.
4. [skill-template.md](skill-template.md) - the mandatory seven-part contract for role, usage,
   rules, inputs, execution, completion, and evaluation anchors.
5. `../evals/rubric.md` - evaluation-surface rules and independent evidence expectations.
